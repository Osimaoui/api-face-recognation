## Navigation et accessibilité
- Le menu principal et ses sous-menus rendent toutes les pages ci-dessus accessibles.
- Un moteur de recherche situé dans l'en-tête renvoie vers la page `/recherche`.
- Les liens de pied de page répètent les accès vers les sections principales et le contact.
