# Prompt récapitulatif du site TELEDYNE

Crée une application front React (Vite) pour TELEDYNE, spécialiste de la distribution de matériels informatiques et de solutions de traçabilité. Utilise la palette bleu nuit #123465, accent orange #f9a836, fond gris clair #f5f7fb et la police Inter/Roboto. Prévois une navigation responsive avec logo, recherche, menus et sous-menus complets (Produits, Solutions, Services, A-propos, Contact) et un footer cohérent.

Page d’accueil :
- Hero full-width avec overlay renforcé, texte contrasté, CTA “Découvrir nos solutions” et un slider d’images de fond en rotation.
- Blocs Produits et Solutions qui n’affichent qu’une sélection (produits phares, 4 solutions max) avec visuels, avantages, icônes et boutons “Voir tous les produits” / “Explorer toutes les solutions”.
- Sections Services, Partenaires technologiques, Références et Newsletter, avec cartes colorées, images illustratives et micro-animations (hover, fade/slide). Partenaires présentés dans un slider/boîte à défilement automatique.

Pages supplémentaires :
- Routes React Router couvrant le sitemap (produits par catégorie, solutions sectorielles, services, à-propos, contact, recherche) avec modèles de pages réutilisables, héro/breadcrumb et CTA vers le contact. 
- Contenus de démonstration fournis via un module data centralisé.

Accessibilité et UX : boutons pleins/outline, cartes arrondies avec ombres légères, espacement généreux, responsive mobile/tablette, gestion fiable des sous-menus (hover/focus). Aucune partie backend requise : l’application est 100 % front.
